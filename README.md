# 🚩 坦克大战 Tank Battle

一个纯 HTML + JavaScript + Canvas 实现的经典坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩！

## 🎮 玩法

| 按键 | 功能 |
|------|------|
| `W A S D` / `方向键` | 移动坦克 |
| `空格` / `J` | 开火 |
| `回车` | 快速开始 / 重新开始 |

## 🕹️ 游戏规则

- 消灭每一关的 **20 个敌方坦克** 即可进入下一关
- 敌方坦克共有 4 种类型（不同颜色，高级坦克需要击中 2 次）
- 保护你的 **基地旗帜 🚩** —— 被摧毁即游戏结束
- **砖墙** 可被炮弹摧毁，**钢墙** 无法击穿，**水域** 坦克无法通行
- 玩家拥有 3 条生命，重生后有短暂无敌护盾
- 共 3 个手工设计的关卡，通关后结算总分

## ✨ 特性

- ✅ 纯前端实现，单文件，零依赖
- ✅ Canvas 渲染 + 粒子爆炸特效
- ✅ Web Audio 实时合成的音效（无需音频文件）
- ✅ 敌人 AI（随机走位 + 追击玩家）
- ✅ 子弹对撞抵消机制

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或启动一个本地服务器：

```bash
npx serve .
# 或
python -m http.server 8000
```
